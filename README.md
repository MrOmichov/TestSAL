# SAL

Компилятор школьного алгоритмического языка в байткод JVM. Для разбора используется ANTLR, для генерации классов — ASM.

## Сборка и запуск

Нужны JDK 17 и Maven. В IntelliJ IDEA можно использовать встроенный Maven.

```sh
mvn package
```

В IntelliJ IDEA запустите `org.mromichov.Compiler`, передав в аргументах путь к файлу `.sal`. Компилятор создаст одноимённый `.class` в рабочем каталоге. Например, результат компиляции `example.sal` запускается командой `java example`.

## Синтаксис

Реализованы алгоритмы с параметрами и возвращаемым значением, переменные и присваивание, арифметические выражения, вывод, условия и циклы. Первый алгоритм становится точкой входа программы.

```text
алг главный
нач
цел х := 5
х := увеличить(х)
вывод х, нс
кон

алг цел увеличить(цел а)
нач
знач := а + 1
кон
```

Условия и циклы записываются так:

```text
если х > 0 то
    вывод х, нс
иначе
    х := 0
все

нц пока х < 10
    х := х + 1
кц

нц
    х := х - 1
кц при х = 0

нц для х от 1 до 10 шаг 1
    вывод х, нс
кц

нц 3 раз
    вывод х, нс
кц
```

### Типы и операции

| Тип | Поддержка |
|---|---|
| `цел` | Объявление, присваивание, вывод; арифметика `+`, `-`, `*`, `/`; сравнения `=`, `<>`, `<`, `>`, `<=`, `>=` в условиях и циклах. |
| `лит` | Объявление и присваивание строкового значения, вывод переменной. |
| `вещ` | Объявление и присваивание вещественного значения; арифметика, сравнение и вывод не реализованы для этого типа. |
| `сим`, `лог` | Ключевые слова распознаются грамматикой; операции и литералы этих типов не реализованы. |

Смешанные выражения и автоматические преобразования типов не поддерживаются. В выражениях можно использовать скобки. Вывод принимает переменную; `нс` добавляет перевод строки.

Полная грамматика находится в `src/main/java/org/mromichov/antlr/sal.g4`.
